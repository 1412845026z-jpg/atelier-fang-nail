====================================================
① 核心功能：ネイル試着室（Nail Try-on Studio）
====================================================

【定位】
作品区负责"看灵感"，試着室负责"玩"，预约负责"落地"。
用户在试着室里换出一款自己喜欢的美甲，最后一步就是"用这款去预约 / 先发给美甲师咨询"。
这个功能是整个网站的卖点，它的完成度决定网站的档次。

【舞台：真实手部照片 + 代码实时绘制的指甲】
- 底图是一张真实的"素甲"手部照片：俯拍，手背朝上，五指微微张开，短的自然甲，没有涂色，放在洞石台面上（素材见第三部分；没有素材时，先用 public/media/veo-keyframes/02-hero-last-frame.jpg 顶替）。
- 指甲不能是贴上去的图片，要用代码按参数实时画出来（SVG 优先）。
- 对齐方法（关键）：照片用 <image> 放进同一个 <svg> 里，viewBox = 照片原始像素尺寸，preserveAspectRatio="xMidYMid slice"。这样不管屏幕多大，指甲坐标始终和照片对齐。
- 每根手指的参数放在 config：甲根中心点 (x, y)、指甲方向角、甲宽、自然甲长、透视压缩 scaleY（拇指是侧面，压缩更明显）。
- 做一个校准模式：网址带 ?calibrate 时，每根手指显示可以拖动的控制点（甲根点、甲尖方向点、宽度把手），右下角实时输出 JSON，可以一键复制回 config。不要靠猜坐标。

【指甲本身必须好看（审美底线）】
1. 形状（7 种）：スクエア / スクエアオフ / ラウンド / オーバル / アーモンド / バレリーナ / スティレット。
   每种形状用函数生成路径，参数是甲宽和长度。甲根要有正确的弧线（甲半月那一端的 U 形），侧边平顺，自由边按形状收尖或收方。
2. 长度：3 档（ショート / ミディアム / ロング），切换时指甲平滑"长出来"（路径插值，0.5s）。
3. 颜色：不要做自由取色器，只提供美甲师挑好的色板。色板保证任何组合都好看，这本身就是品牌品味的体现。初始色板（可微调，名字和 works 里的作品名保持同一套语言）：
   乳白 #EDE6DF・素肌ローズ #D9B8A8・桜鼠 #C9B3AE・霧青 #A9BFD4・青磁 #B5C7B4・灰梅 #8E6F78・無花果 #6E3F4A・琥珀 #A26A3F・胡桃 #5A4033・墨 #1F1B1A・柿 #C2643F・苔 #6E7457・葡萄 #4B3A55・真珠 #F1EDE6・銀鼠 #B9B7B2・金茶 #B89462
4. 质感（每种都要有真实的光学表现，不能只是换个颜色）：
   - グロス：一条柔和的长条高光，沿指甲纵向，再加一个小亮点
   - マット：没有锐利高光，表面加 4% 细噪点
   - シアー / ジェリー：半透明，透出底下的自然甲，甲根略深、甲尖略浅
   - パール / シェル：低透明度的虹彩渐变（conic-gradient 叠加）
   - クローム / ミラー：高对比的反光带
   - マグネット（猫眼）：一条闪粉光带，跟着光源移动（这是重点交互）
5. 立体感：横向做 C 弧明暗（两侧边缘暗约 12%，中间亮），自由边一条细亮线表现厚度，甲根边缘 1–2px 羽化（不能像贴纸），延长出来的部分在皮肤上投一个很淡的影子。
6. 设计（艺术层）：
   - フレンチ：微笑线弧度、宽度、颜色可调，最细做到 micro French
   - 細ライン：墨色细线，3–4 种预设线稿
   - 真珠 / スタッズ：甲根处放 1–3 颗小珍珠或金属钉，有高光和阴影
   - ワンポイント：单根手指做重点甲（通常是无名指）
7. 绝对不要：霓虹色、彩虹渐变、满屏闪粉、卡通手、emoji、星星特效、塑料感的平涂。

【交互（底线 + 你的创意）】
- 色板做成一排精致的甲油瓶或色样卡（参考药剂师 / 实验室标签：编号 + 色名 + 质感），不要做成普通的圆形色块按钮。
- 涂色动画：选好颜色后，像刷子一样从甲根刷到甲尖（遮罩沿指甲方向擦过去，边缘带一点笔刷的不规则感），五根手指依次刷，间隔 0.06s。
- 单指 / 全部：点某一根指甲只改这一根，用来做重点甲；"全部"切换回统一。选中的指甲要有很克制的提示（一圈雾蓝细线，或者轻微抬起）。
- 光：鼠标在舞台上移动（手机端用陀螺仪，没有权限时改成手指拖动）会移动光源，所有指甲的高光和猫眼光带跟着变。没有操作时，光源缓慢自己漂移，让画面一直是"活的"。
- 对比：一条可以左右拖的分割线，左边是素甲，右边是你的设计。
- おまかせ：随机生成一款，但只能从美甲师预设的好看组合里抽（最多 2 种颜色 + 1 种艺术），不能真的随机。
- 撤销 / 重置。
- 预设：8 款作品（config.works）各自对应一组参数，一键套用，名字一致（霧青フレンチ、琥珀マグネット……）。
- 性能：pointermove 不能触发 React 重渲染，用 ref 和 CSS 变量直接改；保持 60fps。
- 欢迎你再加一个"让人忍不住截图分享"的瞬间，具体做什么你来定。

【桌面端 / 手机端布局】
- 桌面：手占左侧约 60%，右侧是控制区，分 4 个标签：形 / 長さ / 色・質感 / アート。控制区按杂志排版来，不要做成后台表单。
- 手机：手在上方占约 55svh 并钉住，控制区是下方可以横滑的一排标签和选项。整个试戴过程不需要上下滚动页面。

【可选（第二阶段，做得稳再加）】
「自分の手で試す」：用户上传自己的手照片，依次点 5 个甲根和甲尖（每指 2 下）完成定位，然后在自己的手上试色。不用 AI 识别，完全手动定位，保证稳定。

③ 现有问题（我在 1440 和 375 两个宽度实测发现的）
====================================================

【首屏 Hero】
问题：没有视频时，现在是两张静态图交叉淡入淡出。两张图里手的位置和姿势不一样，所以画面会"跳"。最后露出来的指甲很淡很短，看不出这是一家美甲店。另外"予約"按钮孤零零浮在右侧中间。
改法：
- 磨砂纸改成代码画：一层白色半透明 + backdrop-filter: blur + 纸张颗粒 + 边缘阴影 + 卷角高光，盖在"素甲底图"上。随滚动，纸从右下角卷起、沿对角线揭开（用 3D 旋转或 clip-path 加卷角渐变）。手和纸共用一张底图，永远对齐，不会跳。
- 纸揭开后，用试着室同一套引擎让指甲"自己刷上颜色"（默认是招牌款霧青フレンチ，五指依次刷）。这是首屏的高潮。
- 首屏结束时，同一只手平滑移到左边，控制区从右边滑入，直接变成试着室。首屏 = 试着室的开场，中间不要断开。
- 首屏最后的按钮改成两个：「試してみる」（主按钮）+「予約」（文字链接）。
- 保留 ScrollSequence 引擎：以后放进 hero.mp4 时，视频尾帧必须就是这张素甲底图。

【顶栏 Header】
问题：顶栏完全透明，滚到服务区和预约区时，正文和导航文字叠在一起（实测"メニュー"和"オフ&ケア"重叠）。
改法：离开首屏后，顶栏加实色燕麦白底和一条 1px 底线；往下滚时隐藏，往上滚时出现。不要用毛玻璃。导航加一项：試着 / Try on。

【作品 Works】
问题：从第 1 张开始，左边是空的，卡片全挤在右边，构图失衡。上方留白太大，也没有区块标题。8 张照片都是米色手配米色墙，看起来很单调。底部的同色柔光几乎看不见。
改法：从中间那张开始（或做成无限循环），加一个小标题（Works · 08）。柔光的强度提高到肉眼能看出颜色变化。详情里加「試着する」。另外在 README 里写清楚：作品图要换成美甲师本人的真实作品。

【菜单 Services】
问题：日文标题在词中间断行（"手描きアー / ト"、"スカルプ長 / さ出し"，手机端也是"…長さ出 / し"）。左上角"01 / 04"被顶栏压住。4 张服务图和作品图是同一批图片（文件 MD5 完全相同）。
改法：所有日文标题加 word-break: keep-all; line-break: strict; text-wrap: balance，必要时按词组插入 <wbr>；标题字号上限调小一档。内容区上边距让出顶栏高度。服务图换成和作品不同的图片（工作台、工具、过程特写等）。

【五层分解 Exploded】
问题：甲片只占屏幕约 20%，形状看起来像一叠椭圆或隐形眼镜，不像指甲。标注字又小又淡，没有标题，最后那句总结也没出现。合拢时甲片会盖到顶栏上。
改法：直接复用试着室的指甲渲染（同样的形状和质感），放大到约 55vh 高。如果用户已经在试着室做了设计，这里就分解用户自己的设计。标注字号 ≥14px，用主文字色。加标题「5 LAYERS / 5層構造」。最后合拢时出现："見えるのは1枚。重ねているのは5層。" z-index 不能盖过顶栏。

【预约 Booking】
问题：用户什么都没选，摘要里已经显示了日期和时间（默认选好了第一个营业日 13:00）。"下一步"按钮只有一个箭头加一条线，没有文字。手机端步骤列表占了半屏。
改法：服务、日期、时段默认都"未選択"。下一步按钮写「次へ」。手机端步骤改成顶部一行"1 / 4"加细进度线。顶部接入"试戴设计卡"（见 ②）。

【加载和性能】
问题：手机端加载页走了 3 秒以上。控制台有 8 个 404：在探测并不存在的 hero.mp4、帧文件夹和 finale.mp4。图片是 600–800KB、896×1200 的 JPG。
改法：config 里加 hasHeroVideo / hasFinaleVideo 开关，为 false 就不发请求。加载页最多只等首屏底图，并且不超过 1.2 秒。所有图片转成 WebP（加 AVIF），用 srcset 输出 2–3 个尺寸，首屏以下懒加载。目标：手机 4G 下 LCP ≤ 2.5s，CLS ≤ 0.1，控制台 0 报错。

【SEO 和分享】
- 加 meta description 和 OG / Twitter 卡片（og:image 用设计卡风格做一张）。
- 加 favicon。
- 切换语言时同步改 <html lang>。
- 加 JSON-LD：schema.org 的 NailSalon 类型（名称、地址、营业时间、价格区间、Instagram 链接）。价格和地址从 config 读，保证和页面一致。

## 第三部分：要你自己生成的素材（发给 Gemini 生图 / Google Flow）

### 1. 素甲手部底图（最重要，试着室和首屏都用它）

```text
Photorealistic top-down photograph, 16:9 landscape, very high resolution. A woman's left hand resting flat on a warm beige travertine stone surface, back of the hand facing the camera, fingers relaxed and slightly spread apart so every nail is fully visible and not overlapping. Short, clean, natural bare nails with NO polish, neatly filed round, healthy pink nail beds, tidy cuticles. Hand centered, filling about 45% of the frame, wrist entering from the bottom edge. Soft, even, diffused daylight from the top left, very gentle shadow, no harsh highlights on the nails. Natural skin texture with fine detail, realistic proportions, exactly five fingers. No rings, no jewelry, no text, no watermark. Calm, minimal, editorial beauty photography.
```

**检查**：5 根手指都在，指甲没变形、没有互相遮挡，指甲上没有涂色。

### 2. 作品图和服务图
- 作品图：最好换成你自己做过的**真实作品**。用同一面墙、同一时段的自然光拍，统一调色，竖版 3:4。
- 服务图：拍工作台、工具、涂的过程、手部护理的特写。不要和作品图重复。
