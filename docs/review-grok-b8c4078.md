## 这一版要改成什么

`b8c4078` 已经把配色、字体、留白和一部分文案转到日本女性向，闭着的花苞静帧也有品牌感。但整站仍是互相割裂的板块：花苞一截、圆角卡片里的手一截、再切到可转的瓶子、再切到金环展架、再切到咨询表单。交互靠说明文字在教人怎么玩，揭晓时花瓣也没有真正落在甲上。

**目标：** 从头到尾是一条连续的交互动画，一镜到底。客人始终在同一只手、同一个空间里；镜头连续地推、移、对焦，把定番、セルフデザイン、设计卡，以及投入之后才出现的オーダーメイド，串成一部短片，而不是一页页官网。提示不靠文字，靠光、微动和镜头。美工要接到照片里的那个世界，而不是旁边另放一套 CG。

## 硬规则

- 遵守 `/workspace/atelier-ui-guide.md`：禁止小游戏和拟物工具操作；每一步只用轻点或滑动，选中后由镜头揭晓；三档是 `定番` / `セルフデザイン` / `オーダーメイド`，像品牌产品线而不是价目表；定番与セルフデザイン都落到同一张设计卡；`もっと、あなただけの一枚を。` 只出现在已经选出或做完、设计卡已生成的结尾；首页不硬推咨询和オーダーメイド。
- **一镜到底。** 禁止把体验拆成各自有标题、编号、不同背景和硬切的区块。滚动或滑动时，镜头应在同一空间里连续运动（推近、横移、轻微绕看、改对焦），不要黑场跳切，也不要「上一屏结束、下一屏重新开场」。
- **同一只手、同一个空间、同一套光。** 花苞、定番、セルフデザイン、设计卡，都发生在这只手所在的那张缎面／化妆台里。3D 与照片必须共享光源、色温和阴影方向，不能一个在写真里、一个在灰色工作室里。
- **零说明文字。** 删掉所有操作提示、解释性副标题、板块编号和长段描述，包括但不限于：`トレイを回す`、`チップを回して選ぶ`、`03 — チップ見本`、`04 — サロンについて`、`05 — カウンセリングカード`、`12 デザイン・イメージ`，以及沙龙那一段介绍正文。不要用文字教人「请转」「请拖」「往下看」。需要暗示时，只用动画和视觉：光的引导、可选项的微动、景深把焦点送到下一步、被选中物轻轻迎向镜头。
- **允许留下的文字只有这些：** 品牌名 soū / soū nail atelier；少量诗性短句（全站不超过三处，且只落在情绪点上），现已定稿的是 `ひらいてみてください。` 与 `花びらが、指先に。`；款名（如 `ちゅるんミルクベージュ`）；价格与目安时间；必要的顶栏导航（`ネイルを選ぶ` / `デザイン` / `サロン` / `相談・予約`）；设计卡上的番号与设计名；图片上克制的 `イメージ` 标记。行动类短词（如保存）只出现在设计卡上，且不要写成说明书。
- 花瓣必须是与定番一致的ショート～ミディアム（ラウンド / オーバル / スクエアオフ），并**真正落到五指的甲面上**，与甲床贴合。禁止再出现悬空、过大、长尖的花瓣。
- 去掉金色圆环展示架，去掉描边硬、像库存模型的 CG 瓶子转盘。チップ要统一成真实甲片的厚度、C 弧和甲根，不要石子、糖葫芦、展架插针。
- 咨询不要做成 01/06、「次へ」式向导。先出订制单一样的设计卡；オーダーメイド只作为卡片结尾的轻入口。

## 一镜到底的叙事（方向，不是分镜脚本）

一条镜头，一个空间。建议的情绪顺序如下，运动方式由你设计，但中间不能断成新页面：

1. **花苞** 在手的空间里轻轻存在。一次轻点或滑动后，镜头缓慢靠近，花瓣展开并准确落成手上的短ジェル，再显现 `花びらが、指先に。` 主行动是 `ネイルを選ぶ`，不要并列推销咨询。
2. **定番** 镜头仍留在这只手上，12 款在同一空间里被看见、被选中（可以是身边浮现的チップ或色的变化，但不是切到另一块展架）。选中后镜头推向甲面，光泽被看清，再生成设计卡。
3. **セルフデザイン** 若客人要自己设计，镜头不离开这只手，按甲型 → 長さ → 底色 → 質感／技法 → 点缀逐步揭晓，每步轻点或滑动，选完自动下一步，可回退。色板是独立的 16–20 种具名色，和谐的靠前、不和谐的淡化。
4. **设计卡** 从同一空间里显现，像高端品牌订制单：番号、设计名、细金线、可保存、可分享，也可带进 LINE。到这里，路径已经完整。
5. **オーダーメイド** 只在卡片已生成后，用 `もっと、あなただけの一枚を。` 轻轻邀请。不要开场就摊开三档价目。

「サロン」若还需要，也只是同一空间里极短的一瞥（只出手、不出脸），不要另起一章带长文。页脚可以极薄地收住，但不要用它重新开一场。

## 美工：这一版的具体问题，以及要达到的标准

对照 `b8c4078` 的实际画面（`/workspace/review-shots/`）：

- **花瓣甲型与落点。** 闭花苞（`local-1440-01-hero.png`）已有静气，但花瓣是长尖甲，和后面短ジェル不是同一语言。揭晓（`local-375-02-hero-revealed.png`、`local-1440-02-hero-revealed.png`）更是失败：几片过大的尖瓣悬在手上方，短甲已经在照片里，3D 没有贴上去。标准：花瓣即定番那种短チップ；落定后应看成「花瓣变成了这只手上的甲」，允许极短的衔接，不允许停在半空。
- **去掉金环展架和 CG 瓶子。** 化妆台（`local-1440-03-vanity.png`）上半的手和标题是对的，下半托盘描边硬、盖子像模型，整段像可转着玩的展柜。見本（`local-1440-04-tips.png`）是金色圆环插着形态不一的片子，像糖葫芦／饰品架。标准：不要这类道具骨架。若还需要 3D，它必须像放在这张缎面上的真实チップ或玻璃瓶静物，和照片同一套窗光，而不是另开一个灰白的 3D 工作室。
- **チップ几何统一。** 见本里有的像石子，有的偏长，侧壁和甲根交代不清。标准：统一真实ジェルチップ的厚度、C 弧、甲根弧线；12 款靠颜色和技法区分，不靠轮廓五花八门。
- **3D 与照片同一光影世界。** 现在是「漂亮的手部写真 + 旁边一套塑料质感的实时渲染」。标准：同一色温、同一主光方向、阴影软硬一致；合成边缘不能发糊、发亮或浮起。宁可少做 3D，也不要两套世界并置。
- **设计卡，不是流程表单。** 现咨询页（`local-1440-06-counseling.png`）是 01/06、进度点、「次へ」的向导卡。标准：先是一张值得保存的订制单（纸感、细金线、番号、设计名）；咨询只作为其后的轻入口，不要把「迷ったら、まず相談だけでも。」做成整段的大标题去抢设计卡。

手部短甲成品照片（化妆台上那张乳贝短甲）要保留，并作为全站甲型与光的基准。揭晓、定番切换、セルフデザイン的结果，都应对齐这套比例和质感。

## 保留什么

- 配色（シアーミルク、ピンクベージュ、ローズブラウン、くすみローズ、克制的金只用于极细线与番号，不要做成展架金圈）。
- 字体（细明朝标题、细正文、Garamond 番号），以及大面积留白。
- 已定稿且自然的短句与款名：`ひらいてみてください。` `花びらが、指先に。` `ネイルを選ぶ` `ちゅるんミルクベージュ` 等 12 款原名；`もっと、あなただけの一枚を。` 仅用于设计卡结尾。
- 短甲成品照片，以及图片上克制的 `イメージ`。
- 页脚的克制气质可以留，但去掉说明腔，不要再堆板块感。

`指先に、季節をひとつ。` 与 `静かな光の中で、丁寧なジェルを。` 可以留作全站诗性额度里的备选，但不要再做成带编号的章节标题。

## 性能

当前构建里灯光相关分包过大，必须拆掉或换成极轻的方案。首屏只先出花苞静帧，3D 进视野再加载；手机 dpr 上限 1.5；中端安卓 3D ≥ 50fps；控制台无报错、无无效预加载。一镜到底不能靠把所有 3D 一开始全部载入来换连续感——用同一场景的持续存在，加上按需显现，而不是一次塞进整部片子。

## 自由发挥的空间

镜头如何在一只手上走完全程、定番如何在不切开空间的前提下被看见、和谐色如何只靠明暗和景深来暗示、设计卡如何从这只手里「生长」出来：都由你发明。也可以让保存设计卡成为全片唯一想截图的高潮。

不要做：把一镜到底做成无法退出的强迫滚动游戏；为了连续而加上操作说明；为了美工再堆金圈、粒子、闪亮转盘；把咨询表单改个皮再放回来；在首页并列三档价目。

## 验收清单

- 从花苞到设计卡（以及可选的オーダーメイド）是同一只手、同一个空间、同一台连续镜头，板块之间没有硬切、没有各自重新开场的章节感。
- 全站无操作提示、无解释性副标题、无板块编号、无长段说明。不出现 `トレイを回す`、`チップを回して選ぶ` 及同类句子。留下的文字只限于硬规则允许的那些。
- 需要动作的地方，只靠光、微动、景深和镜头就能懂；只需轻点或滑动，没有拖转机关，没有小游戏。
- 花瓣是短甲，揭晓后准确贴在五指甲面上，不再悬空、不再是长尖瓣。375 与 1440 都成立。
- 没有金色圆环展示架，没有 CG 感的可转瓶盘；チップ几何统一，3D 与照片同一套光影。
- 三档结构与设计卡漏斗符合 `/workspace/atelier-ui-guide.md`：定番与セルフデザイン都落到订制单式设计卡；咨询不是默认终点；`もっと、あなただけの一枚を。` 只在投入之后出现。
- 配色、字体、留白和短甲成品照片仍在；关键日文为原文。
- 首屏 JS、LCP、帧率达到硬规则里的性能底线；`Lightformer` 量级的巨大分包不再出现；控制台干净。
