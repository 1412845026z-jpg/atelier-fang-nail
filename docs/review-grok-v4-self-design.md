## 0. 先改：舞台日式化（影响全部素材，出视频前完成）

**现状判断**：12 款甲本身是地道的日式サロン审美（短椭圆、くすみ色、透感、极细法式、マグネット、べっ甲），保留。
问题在甲以外：粉色反光缎面 + 珍珠串 + 白芍药，更像欧美/中式婚礼、珠宝广告的「名媛风」，甜、亮、满，与「清透、从容、高级」相反。

**目标**：日本高端サロン作品图的气质——素、静、留白。

**硬规则**
- 底：哑光材质（米白亚麻、和纸、浅木、石材之一或组合）。禁止反光缎面。
- 光：柔和窗边侧光、自然阴影；禁止棚拍式均匀打光。
- 道具：一画面最多 1–2 样，点到为止（一两片花瓣、一枝雪柳/小花、一只陶器）。去掉珍珠串。
- 手：同一只手贯穿全片（一镜到底前提），姿态可比现在更放松自然；戒指可留可去，但全片统一。
- 主色仍服从品牌色板：#F7F1EE / #EFE3DE / #3B2B2C / #7E6B6C / #C9989A / #C7A97F / #2A1D1F。

**素材逐张处理**
- `plate.jpg`：按上面规则重出，作为全片母版，其余图都以它的光位、底材、手姿为准。
- 12 款定番手图：在新 plate 上重出（甲面设计不变）。顺带解决辨识度：
  - 01 ちゅるんミルクベージュ：要透出甲床的奶白，现在偏黄、偏不透明。
  - 10 パールパーツ：珍珠只在一指一小簇，太弱，增加到 2 指并更清楚。
  - 12 ラメグラデーション：指尖亮片密度加大，缩略图上也能看出渐变。
  - 验收：12 张缩到 200px 宽排在一起，每张都能一眼分辨（尤其 02/05/10/12）。
- `petals-on-nails.jpg`：重出。花瓣裁成与指甲等大的短椭圆，顺甲面弧度弯曲，边缘微透光，与甲面交界有极细接触阴影——看起来是「花瓣变成了指甲」，不是贴纸。不得盖出指侧。
- `flower.jpg`：底材与光换成新 plate 同一套，保证镜头 1 接后续不跳色。
- 甲油瓶：外形统一、质感很好，保留。05 极细フレンチ瓶子现为不透明纯白，与手上「透粉底 + 极细白边」不符，改成透粉瓶身（可瓶口带一点白）。瓶子背景同样换哑光底。
- 空白设计卡：可用；背景随舞台更换。

**视频**：以上首尾帧改好后，用户本人在 Google Flow / 可灵用首尾帧生成，再放进仓库。不配置 API Key 自动调用。

## 1. セルフデザイン 的定位

三档：定番（低，12 款直接选，LINE 预约）→ セルフデザイン（中，网站上自己设计，LINE 预约）→ オーダーメイド（高，LINE 一对一，主理人亲自设计）。
セルフデザイン 的意义：让客人以中端价格「参与高端设计的过程」。不咨询也能尽兴地玩完整个流程；玩完有了投入感，自然想要更进一步的オーダーメイド。

## 2. 核心体验（目标，不是步骤）

- **同一部片子的下半场**：同一只手、同一个舞台、同一套光，从定番无缝接入，画面不切走、不跳页。
- **甲在客人眼前长出来**：从素甲开始，每一个选择当场落在这只手上，甲面实时变化，镜头随之有电影感的推近/对焦。
- **空瓶是这段的主角与进度**：已有素材「セルフデザイン 空瓶」。每选一步瓶中多一层，用瓶子被装满表达进度，不出现「STEP 1/6」「第几步」等文字。
- **顺序**：甲型 → 长度 → 底色 → 技法 → 点缀 → 设计卡。选完一项，下一项立刻自然浮现；任何时候可回到前面任一层修改（例如点瓶中那一层，镜头退回）。
- **零说明文字**：用光、微动、景深、淡入淡出引导「这里可以点」，不写操作说明。
- **有限的自由**：推荐的组合更亮，搭不上的选项自动淡下去，客人挑不出难看的组合。这正是「高端设计」与「随便配」的区别。
- **收尾**：瓶子封口 → 镜头拉远 → 变成设计卡（自动生成诗性款名、预计价格、预计时长、卡号），卡上可「LINE で予約」。设计卡出现之后才淡出升级线「もっと、あなただけの一枚を。」引向オーダーメイド；首页与流程中不推オーダーメイド。

## 3. 选项范围（由主理人确定名称与色值，先用占位）

- 甲型 3 种 × 长度 3 种。
- 底色 16–20 色，每色有日文名（主理人命名），偏日式くすみ/透感系。
- 技法 5–6 种（如ワンカラー、フレンチ、グラデーション、マグネット、ニュアンス、ミラー）。
- 点缀 4–5 种（如パール、ラメ、ストーン、ゴールドライン、なし）。

## 4. 写实度要求（实现方式自由）

组合数多，不可能每种出照片。要求的是结果：任意组合下，甲面都与写实手部照片处在同一光影里——有甲面弧度、高光、透感层次和边缘，不能像平涂色块或贴图。
（参考思路，可不采用：写实手部底图 + 每种甲型×长度的甲面遮罩 + 实时着色/光泽 + 技法纹理层 + 实拍点缀小部件合成。）

## 5. 绝对禁止

- 小游戏 / 美容小游戏感：不得出现捏、刷、镊子、转盘、拖拽涂色、得分、音效奖励等。
- 拟物工具表演、卡通或 CG 塑料感。
- 页面出现 AI 字样或任何 AI 相关描述（AI 只是主理人的幕后设计工具）。
- 说明文、步骤编号、操作提示文字。
- 冷启动加载画面打断「一镜到底」。

## 6. 验收标准

- [ ] 舞台已换成哑光日式底材 + 自然侧光，无缎面、无珍珠串，道具 ≤2。
- [ ] 12 款缩略图并排可一眼分辨；花瓣落甲贴合甲面、不出指侧。
- [ ] 从定番进入セルフデザイン 全程无硬切、无跳页，同一只手。
- [ ] 每一步选择即时落到手上，镜头有连续运动；可回退任意一步且画面连贯。
- [ ] 全流程零说明文字；仅保留品牌名、≤3 句诗性短句、选项名、价格、时长、导航、卡号与款名、「イメージ」标注。
- [ ] 任意组合甲面写实、与手部同光影，无色块感。
- [ ] 设计卡生成后才出现升级线；可直接 LINE 预约。
- [ ] 手机（375 宽）首要体验，≥50fps，dpr ≤1.5；首屏不被大体积 3D 包阻塞。
- [ ] 交付时写明：偏离了本规格哪些地方、为什么更优。
