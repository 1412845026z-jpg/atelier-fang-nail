# soū nail atelier · v5 创意方向：从「展示一只手」到「拍一支广告片」

配合：`atelier-ui-guide.md`（定位与三档）、`atelier-v4-self-design-spec.md`（セルフデザイン 规则）。
本文件取代 v4 对「画面怎么做」的全部要求。v4 的写实素材世界观不再是约束（见 2B），做法与视觉语言都可重来。
只写目标、硬规则、验收标准；具体创意与实现自由发挥，鼓励大胆。

---

## 1. 用户的判断（v4 为什么不是商业级）

用户原意：同样的素材、同样的内容，可以做得好得多。现在像「几张图片加动效，首尾剪一段视频」，不是商业级宣传。

根因（第一性原理）：
1. **主角选错了**：把一只纹理清晰到毛孔的写实手平摊在桌上当主角，等于产品规格照。AI 手越清晰越容易怪，整体反而难看；一只手一直单独摆在那里，很丑。
2. **画面是拼的**：花、手、瓶、花瓣、按钮各自生成或叠加，光向、颗粒、清晰度、色调不统一，所以「一看就是插上去的」。
3. **运动是假的**：静图的平移与叠化，没有镜头语言（推拉、焦点转移、光扫过），没有节奏，流畅度不够。
4. **没有声音**：缺少材质感的微音效。
5. **风格断裂**：设计卡后接图库感的沙龙笔刷照；选项是普通网页胶囊按钮。

## 2. 方向：手是符号，甲是主角，光是情绪

- **手可以象征化**：不必清晰到纹理。可以从亚麻褶皱、光影、花瓣之间只露出指尖；可以是浅景深里柔焦的轮廓、逆光剪影、半截入画。观众知道那是手就够了。
  （参照感受：用户之前给的「从袖口拉出、露出美甲」短视频——手并不精细，但甲的转换有创意、有惊喜。只借感受，不得照搬「袖口 + 丝带 + 拉出手」组合。）
- **焦点永远在甲面**：甲面清晰、有光泽与透感；其余可虚。镜头追的是甲的变化。
- **光影是第一设计要素**：窗光的移动、光斑扫过甲面、花影落在布上，用光来引导视线与表达情绪，代替一切说明文字。
- **艺术感优先于说明性**：每一帧先问「像不像美妆广告的一帧」，再问「信息是否完整」。


## 2B. 视觉基调：艺术创意，不是写实（用户 2026-11-23 定，优先级最高）

- AI 生成的写实（布纹、皮肤、台面、花）即使很逼真，也有很强的 AI 感，容易穿帮。**全站不以写实为主基调。**
- 要的是**艺术与创意**：可以有大片感、科技感；可以多种元素、多种色彩组合；可以是插画、抽象、图形、光效、粒子、流体、材质拼贴、3D 抽象造型等任意手法的组合，由你自由决定，但必须有艺术感，并服务同一条创意主线。
- 写实只作点缀，不作全程；手可以是符号、剪影、线条、光影、抽象造型，甲面可以是艺术化的色彩与材质表达。
- 「哑光亚麻、橡木、窗光、洋牡丹、空瓶」是 v4 的写实世界观，**不再是约束**，只作可选灵感；可整体替换为更有创意的视觉语言。
- 仍须保留：品牌的克制与高级感、日本高端美甲的审美气质、甲面颜色与款式在画面中可被辨认（客人要能看懂自己选的是什么颜色和效果）。

## 2A. 核心原则：整站就是一支交互式广告片（用户 2026-11-23 定）

- 网站不再按「菜单 / 价格表 / 作品集 / 咨询 / 预约 / 注意事项」一块块列出来。所有要传达的内容，都塞进一支从头贯彻到尾的商业级交互动画里，用视觉传达和视觉交互讲出来。这就是本项目的 UI 设计。
- 必须在片子里被「看懂」的信息（以画面和极轻排版表达，不写说明文）：
  - 品牌是谁、什么气质（开场）
  - 三档服务：定番（直接选）→ セルフデザイン（自己设计）→ オーダーメイド（一对一，设计卡之后才出现）
  - 每款/每个组合的价格与时长
  - 如何预约与咨询（LINE で予約，自然地出现在故事里的实物上，如纸卡、印章、信封等，方式自定）
  - 店铺信息（地点、营业时间、交通）与必要注意事项（取消规则等）——可以是片尾的一张纸、一封信、一枚名片式的画面，信息完整但不像表单
- 素材与风格**可以扩充**：在不破坏连贯创意的前提下，可加入新的素材、场景、质感或视觉手法（例如和纸、水面、光影、织物、微距材质、抽象色彩流动等）。判断标准只有一个：是否服务于同一条从头到尾的创意主线。
- 风格参考：日本高端美甲沙龙与日本高端美妆品牌的视觉（克制、留白、光、质感、季节感、日文排版）。需自行检索真实的日本高端沙龙/品牌官网与作品图做研究，只借气质与完成度，不复制任何具体画面、文案或创意。交付时附上你参考了哪些、借了什么。

## 3. 让画面「长在同一个世界里」（解决拼贴感）

目标：任何元素都不能看起来是贴上去的。实现方式自由，以下是必须达到的结果：
- 全站统一的一层「胶片」：同一套调色（暖、低对比、轻微提亮暗部）、同一种细颗粒、同一个暗角，覆盖所有图片、视频、合成元素与 UI 卡片。
- 场景内元素（瓶子、色样、设计卡、花瓣）必须与环境同光向、有接触阴影、处在同一景深体系里。
- UI 只允许两种存在方式：① 场景中的实物（纸、瓶、色样卡）；② 极轻的排版文字。禁止浮在画面上的通用网页控件（胶囊按钮、轮播滑条、白底圆角卡）。
- 不出现与世界观不符的图（图库感沙龙照、冷白诊所光、拿笔刷的手等）。
- 如图像清晰度/像素有问题，宁可整体柔焦加颗粒统一质感，也不要局部锐利、局部糊。

## 4. 运动语言（解决流畅度）

- 用**镜头**讲故事：推、拉、摇、焦点转移、光扫；而不是图片平移与淡入淡出。
- 转场用**形状与颜色的匹配剪辑**：花瓣的弧线 → 甲面的弧线；瓶中液体的颜色 → 甲面的颜色；一道光扫过即完成换款。
- **甲的转换要有创意与惊喜**：颜色像墨滴入水般从甲根晕开、光带扫过后显色、花瓣融化成凝胶等，方向自定，但每一次变化都要有「啊」的瞬间。
- 节奏有呼吸：快慢交替、停顿留白；所有动效 60fps，缓动曲线考究，滚动/触控跟手无卡顿。
- 关键段落（开场花开、花瓣落甲、换款）可用视频（Google Flow / 可灵，用户本人生成），其余用实时合成；两者之间不得看出接缝。

## 5. 声音

- 极轻的材质音效：玻璃瓶轻碰、瓶身滑过、布料摩擦、花瓣飘落的气息、选项切换的细微「定位感」声。
- 克制：音量低、短、干净；不能有游戏感（金币、叮咚奖励、夸张音效）。
- 默认静音，右上角一个极简声音开关（浏览器自动播放限制，且日本用户多在公共场合用手机）；开启后全程生效。

## 6. 场景骨架（主理人建议，可推翻、可创新）

1. 光里的花苞，窗光缓缓移动，花开。
2. 花瓣飘落，镜头跟随；亚麻褶皱与光影之间，指尖若隐若现。
3. 花瓣落在甲上，匹配剪辑变成凝胶甲面，光扫过。——「花びらが、指先に。」
4. **定番**：镜头沿台面滑过立在桌上的瓶子，焦点在瓶间转移；对焦到哪瓶，甲面就以有创意的方式变成那款。款名/价格/时长以极轻排版出现。
5. **セルフデザイン**：空瓶登场（入口需与定番清楚区分，用画面而不是同名按钮表达）。选项是台面上的实物（色样卡、甲型样片、小点缀），每选一项，甲面变化、空瓶多一层颜色；可点瓶中某层回退。
6. **设计卡**：纸卡落在同一束光里，活版印刷质感；保存/分享/LINE で予約。之后才淡出「もっと、あなただけの一枚を。」
7. 收尾：店铺信息、预约方式与注意事项以片中实物（纸、信、名片等）呈现，光渐暗，品牌名。整站从头到尾是一部片子，没有传统的信息板块。

## 7. 硬规则（沿用）

- 不做小游戏 / 美容小游戏；无捏、刷、镊子、转盘玩法、得分。
- 不出现说明文、步骤编号、操作提示；不出现 AI 字样。
- オーダーメイド 不在首页推，只在设计卡之后出现。
- 手机竖屏优先构图（375 宽），桌面另行构图，不是简单裁切。
- 依赖保持精简，首屏快；不阻塞「一镜到底」的首帧。

## 8. 验收标准

- [ ] **录屏验收**：交付 375 宽手机与 1440 宽桌面各一段完整滚动/操作录屏（mp4，含声音开启版）。随手截一帧都能当美妆广告海报；整段看下来像一支广告片，而不是网页加动效。
- [ ] 没有任何元素看起来是贴上去的：光向、阴影、颗粒、调色、清晰度统一。
- [ ] 整体以艺术创意为基调而非写实；无 AI 写实穿帮感（怪手、假布纹、塑料皮肤）；手不再是摆拍主角，焦点在甲面。
- [ ] 无叠化式硬转场；转场为镜头运动或匹配剪辑；全程 60fps、跟手。
- [ ] 每次换款都有一个有创意的甲面转换瞬间。
- [ ] 音效克制、默认静音、开关可用、无游戏感。
- [ ] 无通用网页控件浮在画面上；无图库感/冷白光图片。
- [ ] 不看任何传统信息板块，仅凭片子就能获知：三档服务、价格与时长、预约/咨询方式、店铺信息与注意事项。
- [ ] 新增素材/风格均服务于同一条创意主线；附日本高端沙龙/品牌参考清单与借鉴点。
- [ ] 定番与セルフデザイン 入口在画面上一眼可分，且不靠说明文字。
- [ ] 交付说明写明：偏离了本文件哪些地方、为什么更好。
